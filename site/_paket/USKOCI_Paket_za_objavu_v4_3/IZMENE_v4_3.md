# USKOČI v4.3 — 8. oktobar 2026.

## Stvarne promene
1. Uslovi: eksplicitni zakonski izuzeci odustanka, ograničenje njihove primene, odvajanje od HITNO/termina i redovnog otkazivanja; istorijski Dogovor se ne prepisuje novim uslovima.
2. Privatnost: precizniji osnovi, osoba bez naloga, obim fotografija i web tehnologija; javna tabela se više ne uzima iz nepotvrđenog nasleđenog predloga.
3. Čuvanje: stari brojevi očuvani u interno/ROKOVI_NASLEDJENI_NEOBJAVLJIVATI.md; novo polje retention_schedule očekuje potvrđenu stvarnu tabelu. Nijedan server ili rok u bazi nije izmenjen.
4. Brisanje: nije predstavljen univerzalni imejl put za sve platforme; objedinjeni su snimci i povezani podaci i jasniji završetak postupka.
5. Pravila: dodat izričit opis zabrane seksualnog iskorišćavanja dece i postupanja; 18+ nije izuzeće.
6. Kako radi/Podrška: ljudski primer i izbor odgovarajućeg postupka, uz očuvanje prava.
7. Ugradnja: odvojeni ugovorni režimi, konkretni izbori ranijeg početka i trajni zapis, Google/Apple razlika.
8. Prijava: dopunjeni privremena obrada/Data safety i minimalni obim dozvola; novi kratak predajni list i zasebne Apple razlike, bez novih javnih stranica.
9. Izvori: razdvojena nova provera javnih izvora od istorijskog GitHub čitanja; naslov Pravilnika nije potvrda službenog priloga.
10. Alati: dosledna verzija, potvrđena tabela kao podatak, označeno nepotvrđeno ime, zaštita od javnog izvoza nedovršenog teksta. Stare slike/provere nisu predstavljene kao nove.

## Šta nije rađeno
Nema nove GitHub analize, promene koda ili baze, testiranja AAB-a, telefona, servera ili živih web URL-ova. Nema podnete Play/App Store prijave. Nisu odabrani pravni oblik, javna adresa, kontakt ili strane države. Nije pribavljen puni čitljiv službeni prilog obrasca odustanka.
