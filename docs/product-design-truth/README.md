# Istorijski inventar proizvoda i dizajna

Ovaj direktorijum čuva rekonstrukciju iz septembra 2026. **Aktuelni UI/UX canon je [Premium White](../implementation/design-system/PREMIUM_WHITE_CANON.md).** [Registar ograničenja](../implementation/design-system/DESIGN_CONSTRAINT_REGISTRY_20261018.md) pokazuje šta je zaštita, smernica ili stari freeze.

MD sadržaj ostaje sačuvan ispod istorijskog zaglavlja. `USKOCI_SCREEN_STATE_MATRIX.json` ima eksplicitnu istorijsku metadata oznaku; svi originalni ekran-zapisi ostaju. `USKOCI_SCREEN_STATE_MATRIX.csv` je neizmenjeni istorijski CSV sa istim značenjem. Njegove kolone „current“ i „canon“ odnose se na datum rekonstrukcije, ne na sadašnji build. CSV nije aktivna lista ruta ni novi backlog.

Tri stare zone, obavezni role switch, ručni editori, stari statusi nedostajućih funkcija i tačna stara geometrija ne vraćaju se kao obavezni zahtevi. Privatnost, prava, revizije, potvrda korisnika i očuvanje unosa proveravaju se u današnjim ugovorima. Status ostaje u [postojećem registru62tokova](../control/redovi.json).
